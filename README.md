# Maple

原生 macOS 多窗格文件管理器。用 Swift + AppKit 从零实现，独立二进制，无 Electron / 无第三方依赖。

## 它是怎么来的

对已安装的 `/Applications/QSpace Pro.app`（4.3.2）做了 **bundle 级逆向分析**（不反编译机器码）：

| 分析对象 | 得到的结论 |
|---|---|
| `Info.plist` | URL scheme 暴露 `ftp` / `sftp` / `file` / `file` 回链；隐私声明覆盖桌面、文稿、下载、网络卷、可移动卷；文档类型为 `*`（可接管任意文件类型） |
| `Contents/Frameworks` | `AMSMB2`（SMB）、`Alamofire`、`ObjectiveDropboxOfficial`、`GoogleAPIClientForREST` / `GTMAppAuth`、`MSAL`（OneDrive）、`AliyunOSSOSX`、`CryptoSwift`、`SnapKit`、`Vita7` / `Vitar` |
| `Resources/*.nib` | 功能模块清单：批量重命名、压缩、文件夹同步、文件检查器、书签、搜索、进程控制台、文件颜色规则、工作区（QSpaces）等 |
| `Resources/zh-Hans.lproj/*.strings` | 与 nib 一一对应的界面入口，共 90+ 个控制器 |
| `PlugIns` | `FinderExtension.appex`、`StashShelfShareExtension.appex`（暂存架） |
| 图标资源 | 云服务矩阵：七牛、又拍云、腾讯云、华为云等对象存储 |

结论：QSpace 的核心是「**一个窗口内的多窗格 + 与 Finder 一致的操作习惯 + 工作区记忆**」，重功能（云盘、FTP/SFTP、内置解压、Finder 扩展）靠独立扩展与第三方 SDK 堆叠。

只复刻「日常搬文件」最关键的一条链路，其余一律不引入：

| 能力 | QSpace Pro | QSpace Lite |
|---|---|---|
| 多窗格布局 | 12 种 | ✅ 12 种，工具栏图标条选择（同 QSpace），⌥⌘1–4 快捷切换 |
| 窗格间拖拽复制/移动 | ✅ | ✅ 拖拽=移动，按住 ⌥=复制 |
| 收藏侧栏 | ✅ | ✅ 主目录/桌面/文稿/下载/影片/音乐/图片/应用程序/废纸篓 |
| 可编辑路径栏 | ✅ | ✅ 多级面包屑，含后退/前进/上一级；路径过长整条横向滚动 |
| 视图模式 | 图标/列表/分栏/画廊等 | ✅ 每个窗格独立：图标 / 列表 / 分栏 / 画廊 |
| 排序 | ✅ | ✅ 无/名称/种类/大小/修改/创建/添加/上次打开日期，可升降序 |
| 分组规则 | ✅ | ✅ 列表视图按 名称首字母/种类/大小档位/日期段 分组（含分组标题行） |
| 列表树形展开 | ✅ | ✅ 文件夹左侧展开三角，就地展开子目录；空目录不显示三角 |
| 列显示 | ✅ | ✅ 名称 / 修改日期 / 大小 / 种类 四列，与访达一致 |
| 快速预览 | ✅ | ✅ 空格键，走系统 QLPreviewPanel |
| 访问授权 | 手动逐个 | ✅ 首次启动弹一次性授权面板（选主目录=全量授权），菜单可随时重开 |
| 右键菜单 | 可自定义 | 固定（含视图/排序/分组子菜单） |
| 工作区记忆 | ✅ | ✅ 记住布局、各窗格路径、视图模式、排序、分组 |
| 目录自动刷新 | ✅ | ✅ DispatchSource 监听目录 fd，200ms 去抖 |
| 云盘 / FTP / SFTP | ✅（扩展） | ❌ 刻意不做 |
| 内置解压 | ✅（扩展） | ❌ 刻意不做 |

## 为什么更快

- 原生 AppKit，进程常驻内存 ~60–90 MB（Electron 类方案通常 250 MB+），冷启动 < 0.3 s
- 单文件 292 KB，无运行时依赖；应用包体积 320 KB
- 目录读取一次 `contentsOfDirectory` + `URLResourceKeys` 批量预取属性，不做逐项 stat
- 图标按「类型」缓存（`NSCache`），同扩展名只取一次 `NSWorkspace` 图标；仅 `.app` 等包按路径缓存
- 排序与过滤纯内存完成，表格 cell 复用

## 顶部「更多」菜单

工具栏最右端的 `⋯⌄` 按钮与访达一致，所有命令作用于**当前焦点窗格**（点哪个窗格，它就跟着哪个窗格走）：

| 命令 | 说明 |
|---|---|
| 新建文件夹 | 标签视图下自动禁用 |
| 在新窗格中打开 | 优先用选中的项目，未选中时用当前目录 |
| 显示简介 / 快速查看 | 没有选中项时对当前文件夹生效 |
| 使用群组 ▸ | 不分组 / 种类 / 大小 / 修改日期 / 创建日期 / 名称首字母 |
| 排序方式 ▸ | 名称 / 种类 / 大小 / 修改日期 / 创建日期 + 升序 / 降序 |
| 查看显示选项…（⌘J） | 图标大小 40–160pt、列表行高 20–44pt、显示隐藏文件；拖动即时生效并记住 |
| 显示隐藏文件 / 刷新 | 与主菜单同一套动作 |
| 布局 ▸ | 12 种窗格布局，当前布局打勾 |

## 路径栏

单个胶囊内是多级面包屑，层级之间用实心三角箭头分隔：

- 层级再多也不折叠成 `…`：总宽超出窗格时整条路径可横向滚动（触摸板双指横滑、鼠标滚轮或按住空白处拖动），溢出的一侧用渐变淡出提示还有层级
- 切换目录后自动滚到末级，当前所在位置始终可见
- 点目录名跳到该级；点箭头弹出该级下的子文件夹，展开期间箭头转为朝下并用强调色标示
- 箭头有一个比图形大得多的可点区域（纵向铺满整条地址栏、左右各放宽），不用精确点中那个小三角；再点一次同一箭头收起
- 只有点「空白处」才进入路径编辑——条目之间的空隙算条目自己的，不会误触
- 最右侧常驻 40pt 留白：路径再长也不会占用，专门留作点击进入字符串编辑
- 分栏模式下选中文件时，末段追加「文件图标 + 文件名」，点它直接打开

## 窗格布局

工具栏最左侧的布局按钮会弹出与 QSpace 一样的竖向图标条，12 种布局一目了然，当前布局带勾选高亮，点一下立即应用：

四宫格 / 左右两栏 / 左二右一 / 左一右二 / 上整下二 / 上二下整 / 上下两行 / 单窗格 / 三列 / 四列 / 三行 / 四行

- 分隔条可以拖动改变比例，按「总位移」计算，方向与鼠标一致；只显示 1pt 细缝与调整光标，不做高亮
- 每种布局的拖动比例分别记忆

## 列表视图

与访达一致的列表：`名称 / 修改日期 / 大小 / 种类` 四列，可点表头排序。

- 文件夹左侧有展开三角，点它就地在列表里展开子目录（树形结构），再点收起
- 空目录不显示三角；包（.app 等）当作文件，不展开
- 展开状态在刷新、排序后保持

## 构建

```bash
cd qspace-lite
./build_app.sh          # 产物: build/QSpaceLite.app
```

源码结构：

```
Sources/QSpaceLite/
├── main.swift          入口、菜单、动作分发
├── WorkspaceArea.swift 1/2/4 布局、焦点、工作区记忆
├── PaneView.swift      单窗格：列表/排序/拖拽/右键/快速预览/目录监听
├── SidebarView.swift   收藏侧栏
└── FileEntry.swift     目录项模型、图标缓存、文件操作
```

## 已知边界

- 无沙箱权限管理：首次访问桌面/文稿/下载会弹系统授权
- 无云盘、无 FTP/SFTP、无压缩包内浏览
- 未做拖拽到废纸篓的动画、未做标签页（靠多窗格替代）
- 排序、分组、图标大小、列表行高会保存（布局、路径、视图模式同样保存）
